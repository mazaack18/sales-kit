# Account Atlas

営業先の組織図と、部署ごとの担当者・外部パートナー・利用SaaSを整理する試作アプリです。初期データは架空です。

## 起動

Node.js 24 で `npm start` を実行します（既定ポート3000、PORTで変更可能）。外部依存パッケージはありません。`npm run check` でJavaScript構文を確認できます。

## 機能

会社・部署の追加、部署の親子関係、担当者・パートナー・SaaS・メモの編集、部署の削除、横断検索、JSON書き出し。

データはブラウザーのlocalStorageに保存します。同じブラウザー・同じオリジンでのみ保持されます。ブラウザーデータの削除で失われるためJSON書き出しで控えを保管してください。JSON取り込み、認証、チーム共有、サーバー保存には未対応です。実際の顧客情報をチームで扱う前に認証とアクセス制御を追加してください。
